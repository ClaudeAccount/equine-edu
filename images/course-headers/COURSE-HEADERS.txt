COURSE HEADER IMAGES — DROP-IN REFERENCE
==========================================
One image per course. Drop each file into this folder
(images/course-headers/) with the exact filename below.

FILE NAME                    COURSE
---------------------------  ---------------------------------
equine-anatomy.png           Equine Anatomy
face-markings.png            Face Markings
leg-markings.png             Leg Markings
base-coat-colors.png         Equine Base Coat Colors
common-horse-terms.png       Common Horse Terms (not yet wired)

RECOMMENDED SIZE
  800 × 600 px minimum
  PNG or JPG both work — rename the extension in the filename if using JPG
  (e.g. equine-anatomy.jpg — then update the src in the course index.html too)

NOTES
  - The pages/ subfolder contains the old per-page images and can be left as-is
    or cleaned out later — the course landing pages no longer reference them.
  - common-horse-terms.png is reserved but needs an image slot added to
    courses/common-terms/index.html before it will show.
