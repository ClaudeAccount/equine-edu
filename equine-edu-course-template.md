# Equine EDU Course Template

**Purpose:** The standard layout for every Equine EDU mini course. A writer should be able to build a complete course from this file alone. Research citations appear in brackets (e.g., [Gagné]) and resolve in Section 7. Citations are for the writer only — never show sources, footnotes, or "according to" statements in learner-facing content.

**Scope:** Subject paths of 3–6 courses; each course is 5–10 pages (Canon C3 Amendment 2), using the existing page types (Index, Why It Matters, Core Content/Catalog, Viewing Room or Study & Review, Training Barn, Study Guide, Test Your Knowledge). This template standardizes what goes on each page; it does not change the platform.

> **Canon errata applied (Canon Resolution Phase 0 v1.0 §6, items 1–5).** This file is read through Canon §1.3. Per Canon C1, the atomic unit "module" used throughout this template = **course** (5–10 pages, Canon C3 Amendment 2); the master template's "mini course (of 3–6 modules)" = **subject path** (3–6 courses); T01's "module list" = **page list** (Canon §1.2). Per Canon C2, the tier names Foundations / Core Studies / Expanding Knowledge are documented aliases for **Round Pen / Schooling Ring / Loft tier**. Where this template and a page-template spec (T01–T07, T16) state the same rule, **the page-template spec is canonical** (Canon §1.3). The specific rule translations enumerated in Canon §1.3 are applied below; any residual "module" wording in prose is read at the level Canon §1.3 specifies.

## How to use this template (authoring order)

Pages are *presented* to learners in the order in Section 1, but they are *written* in backward-design order [Wiggins & McTighe]:

1. Write the course learning outcomes first (Section 3).
2. Write the final quiz and each course's Test Your Knowledge second — every question must map to an outcome.
3. Write content pages last, including only what learners need to pass the assessments and meet the outcomes. Content that doesn't serve an outcome gets cut or moved to an optional "Further Exploration" block [Wiggins & McTighe; Mayer, coherence principle].

This order is the single highest-leverage practice in the research base: it guarantees alignment between objectives, activities, and assessments — the core requirement of the Quality Matters rubric (Standards 2–5) [QM].

## 1. Standard Course Page Flow

The existing Equine EDU page sequence already maps cleanly onto Gagné's Nine Events of Instruction [Gagné] — this is a case where the current structure matches best practice and should be kept. The required order per course (page-template specs T01–T07, T16 are canonical where more specific — Canon §1.3):

| # | Page | Instructional purpose | Research basis |
|---|------|----------------------|----------------|
| 1 | **Index** | Orient the learner: course purpose, page list, outcomes, estimated time, how to navigate. | QM Standard 1 (course overview makes structure clear at the start) [QM] |
| 2 | **Why It Matters / Orientation** | Gain attention and establish relevance; activate prior knowledge with a familiar scenario. | Gagné events 1 & 3 (gain attention, stimulate recall); UDL "recruiting interest" [Gagné; CAST] |
| – | **Concept Foundation** *(conditional)* | The structure/vocabulary the catalog rests on, when a prerequisite exists (e.g., face anatomy before face markings, pigment basics before coat colors). | Structure-before-catalog convention; cognitive load (prerequisite knowledge) [Sweller] |
| 3 | **Core Content / Catalog — one or more pages** | Present new material in small chunks with worked examples and signaled key terms; state course outcomes at the top. **Visual/ID courses use a single Core Catalog page; multi-topic courses use several content pages, one concept each.** | Gagné events 2, 4, 5; cognitive load chunking [Gagné; Sweller; Cowan] |
| 4 | **Viewing Room** *(visual/ID courses)* | Visual study: labeled images, comparisons, galleries. Builds the visual schema before learners are tested on it. | Mayer multimedia principles (contiguity, signaling, segmenting) [Mayer] |
| 5 | **Study & Review** *(multi-topic courses)* | Consolidated vocabulary + key-principles recap across the content pages, organized for self-assessment and Horse Bowl preparation. Sequenced after the content pages, before the Training Barn. | Retrieval/consolidation before practice [Roediger & Karpicke; Dunlosky] |
| 6 | **Training Barn** | Guided practice with immediate feedback; low-stakes, unlimited attempts. | Gagné events 6 & 7 (elicit performance, provide feedback); retrieval practice [Gagné; Roediger & Karpicke] |
| 7 | **Study Guide** *(present in all current courses; required at Loft tier + Horse Bowl feeders)* | Prompt→reveal retrieval review immediately before the quiz; also exported as a printable. | Practice testing + spacing are top-utility; rereading is low-utility [Dunlosky] |
| 8 | **Test Your Knowledge** | Scored retrieval assessment of the course outcomes, mixing current-course and prior-course items. Always the last page; always named `test-your-knowledge`. | Gagné event 8; testing effect; spacing [Roediger & Karpicke; Dunlosky] |
| 9 | **Course wrap-up** (closing section of the quiz results page or final content block — not a new page type) | One-paragraph summary + pointer to where the skill appears next. | Gagné event 9 (enhance retention and transfer) [Gagné] |

**Two production archetypes (matches the 24 built courses; Canon C3 Amendment 2):**

- **Catalog / visual-ID:** Index → Why → [Concept Foundation] → Core Catalog → Viewing Room → Training Barn → [Study Guide] → Test — colors, markings, patterns, parts-of-the-horse, vital signs, riding styles, tack equipment.
- **Multi-topic / content:** Index → Why → [Concept Foundation] → several Content pages → [Study & Review] → Training Barn → [Study Guide] → Test — horse behavior, health & disease prevention, nutrition, hoof care & farriery, gaits & movement, intro to tack.

A course runs **5–10 pages** depending on archetype and which conditional pages apply. The page-template specs (T01–T07, T16, **T26 Study & Review**) and Canon C3 are canonical for structure; this table is the pedagogical view.

**Subject-path-level additions** (Canon §1.3):

- The **final course in a subject path** gets a **cumulative** Test Your Knowledge — at least one-third of items drawn from earlier courses in the path. Spaced re-testing produces stronger retention than end-of-course testing alone [Dunlosky; spaced retrieval meta-analysis]. (T07 spec is canonical for this rule.)
- Each course's Why It Matters (T02) opens with one retrieval prompt referencing the **previous course in the path** ("Before starting, recall the three…"); for the first course in a path it references everyday experience. This is the cheapest way to add spacing without new page types [Roediger & Karpicke].

**Deviation flag:** If the current site ever places the quiz before the Training Barn, reverse it. Practice with feedback must precede scored assessment [Gagné]. No other reordering is needed.

## 2. Page-Level Templates

General rules for all pages: one idea per paragraph; paragraphs ≤ 4 sentences; key terms bolded on first use and defined in plain language immediately [Sweller; WCAG 3.1.5]; every image has descriptive alt text [CAST; WCAG].

### 2.1 Index page

Required sections, in order:

1. **Course title and one-sentence promise** (≤ 25 words) — what the learner will be able to do.
2. **Course outcomes** — 3–5 measurable outcomes (Section 3 formula).
3. **Page list** — title + one-line description per page. (Canon §1.2: T01's "module list" = "page list"; component class names unchanged.)
4. **Time estimate** — per page and total.
5. **How this course works** — 2–3 sentences explaining the page types (Viewing Room, Training Barn, quiz) for first-time learners. [QM Standard 1]

Word count: 150–300 total. No instructional content on this page.

### 2.2 Why It Matters page

1. **Hook** (50–100 words) — a concrete barn-world scenario, question, or surprising fact. Scenario beats abstract claim: relevance is established through situations the learner recognizes [Gagné; CAST engagement].
2. **Recall prompt** (1–3 sentences) — connects to the prior course in the path or to everyday experience.
3. **What this course covers** (50–100 words) — the course outcomes restated in plain language ("By the end of this course, learners will be able to…").
4. **Where it leads** (1–2 sentences) — how this knowledge is used in the next tier, in horse bowl, in judging, or at the barn.

Word count: 200–350 total. No new terminology introduced here.

### 2.3 Core Content page

1. **Course outcomes** — listed verbatim at the top (Canon §1.3: the master's module-objective level collapses into the single course-outcome set; T01 canonical) [QM Standard 2; Gagné event 2].
2. **Content chunks** — one chunk per concept. Each chunk: heading → 100–250 words of explanation → one supporting visual or example. Maximum chunks per course: see Section 5 concept limits.
3. **Worked example** (Foundations and Core Studies tiers) — one fully worked-through example per major concept (e.g., step-by-step identification of a marking from photo to name). Novices learn more from studying worked examples than from unguided problem-solving [Sweller; Kalyuga]. At the Expanding Knowledge tier, replace most worked examples with practice problems — guidance that helps novices hinders advanced learners (expertise reversal effect) [Kalyuga].
4. **Check Your Understanding** — 1–2 ungraded retrieval questions after every 2–3 chunks, answers revealed on interaction. Retrieval beats rereading for retention (61% vs. 40% recall after one week in the foundational study) [Roediger & Karpicke].
5. **Key Terms recap** — bulleted term + one-line definition at page end.
6. **Optional: Further Exploration** — clearly labeled as optional; interesting-but-nonessential material goes here, never inline. Extraneous material depresses learning (coherence principle) [Mayer].

Word count: 800–1,500 per page at Round Pen (Foundations); up to 2,000 at Loft tier (Expanding Knowledge). If a page exceeds this, split it. (Canon §1.3: Core Content word counts read per page.)

Multimedia rules [Mayer]:

- Place labels and captions on or directly beside the image, never in a separate block (contiguity).
- Use arrows/highlights to signal what to look at (signaling).
- Break any process into learner-paced steps; no long unbroken passages next to complex diagrams (segmenting).
- No decorative images inside content chunks; decoration belongs in page headers only (coherence).

### 2.4 Viewing Room page

1. **Purpose line** — one sentence stating what learners should be able to recognize after this page.
2. **Exemplar gallery** — minimum 3 examples per visual category (color, marking, breed type, tack item). Variation within a category is what builds reliable identification [Kornell & Bjork; Kang].
3. **Interleaved arrangement** — mix categories rather than grouping all examples of one category together. Interleaved study of visual categories produces markedly better identification of new examples than blocked study (59% vs. 36% in the foundational experiment) [Kornell & Bjork; Firth]. **Deviation flag:** if the current Viewing Room groups all examples of one item together, this is the smallest highest-value change to make — reorder existing images; no new assets needed.
4. **Contrast pairs** — for commonly confused items (e.g., snip vs. star, bay vs. brown), show them side by side with the distinguishing feature signaled [Kornell & Bjork, discriminative-contrast; Mayer, signaling].
5. **Self-check** — 2–3 "which one is it?" prompts using images not shown above.

Content rules: every image needs alt text that describes the distinguishing feature, not just the name ("bay horse: reddish-brown body with black mane, tail, and lower legs") [CAST; WCAG]. Captions ≤ 20 words.

### 2.5 Training Barn page

1. **Instructions** (≤ 50 words, imperative voice permitted) — what to do and that attempts are unlimited and unscored.
2. **Activities** — 5–12 interactive items per course, ordered easy → hard. Acceptable formats: drag-and-drop labeling, image matching, sorting/classification, sequencing, fill-in-the-blank with word bank (Round Pen only). *(Flag for SME review — Conflict #8: this item-count predates Canon S1, which moved games to single Loft-hosted instances accessed via T06's 2–4 cards. Number preserved unchanged pending review against the T06 spec; not resolved here.)*
3. **Immediate feedback** — every item explains *why* the answer is right or wrong in 1–2 sentences, not just correct/incorrect [Gagné event 7; QM Standard 3].
4. **Mixed practice** — from the 2nd course in a subject path onward, 20–30% of items revisit earlier courses in the path (per the T06 review-mix note) [Dunlosky; spaced retrieval meta-analysis].

### 2.6 Test Your Knowledge page

1. **Intro line** — number of questions, what's covered, that retakes are allowed. (Allowing retakes converts the quiz itself into a learning event [Roediger & Karpicke].)
2. **Questions** — 8–15 per course. Every question maps to a stated outcome; no trivia that wasn't taught [QM alignment].
3. **Feedback on completion** — per-question explanation plus a pointer back to the page section that covers it.
4. **Wrap-up block** — 50–100 word course summary and a one-line bridge to the next course in the path [Gagné event 9].

Question format rules: see Section 4.3 for visual-identification formats. Distractors must be plausible same-category items (for a "star" question, distractors are snip/strip/blaze — not "saddle"), because discrimination between similar categories is the skill being tested [Kornell & Bjork].

## 3. Learning Outcome Formula

**Structure:** `Learners will be able to + [measurable verb] + [content] + [condition or criterion when useful]`

Example: "Learners will be able to identify the four basic face markings from photographs."

Rules [QM Standard 2; Anderson & Krathwohl]:

- 3–5 outcomes per course. (Canon §1.3: the master's two-level course-outcome / module-objective split collapses — one course = one set of 3–5 outcomes; T01 is canonical.) (The specific counts are widely used convention, not experimental findings — what the evidence and QM require is that outcomes be measurable, stated to the learner, and aligned with assessments.)
- Never use *know, understand, learn about, appreciate, be familiar with* — they cannot be assessed.
- State outcomes on the Index (T01) and restate them at the top of each Core Content page (Canon §1.3 — a single outcome set per course).

**Verb lists by tier** (Bloom's revised taxonomy [Anderson & Krathwohl]):

| Tier | Bloom levels | Approved verbs |
|------|-------------|----------------|
| **Foundations** | Remember, Understand | identify, name, label, match, describe, define, list, recognize, sort |
| **Core Studies** | Understand, Apply, Analyze | explain, compare, classify, demonstrate, apply, distinguish, summarize, give examples of |
| **Expanding Knowledge** | Analyze, Evaluate | analyze, evaluate, justify, prioritize, recommend, critique, predict, defend (as in judging reasons) |

This vertical movement up Bloom's taxonomy mirrors how USPC scaffolds D→A certifications (D members *perform and name*; A members *explain, evaluate, and justify*) and how 4-H advancement levels move from safety-and-identification to industry analysis [USPC; 4-H].

## 4. Practice & Assessment Placement Rules

### 4.1 Placement

- **Within Core Content:** ungraded retrieval check every 2–3 concept chunks. Retrieval during reading beats re-exposure [Roediger & Karpicke; Dunlosky rate retrieval practice and spacing as the two highest-utility techniques of ten reviewed].
- **Training Barn:** after all content pages, before the quiz. Practice with feedback precedes assessment [Gagné].
- **Test Your Knowledge:** ends every course; low-stakes; retakes allowed.
- **Spacing:** every quiz from the 2nd course in a subject path onward includes 20–30% prior-course items; the final course's quiz is cumulative. Spaced retrieval outperforms massed retrieval in classroom-scale studies [spaced retrieval meta-analysis; Dunlosky]. (T07 spec is canonical for this rule.)

### 4.2 Stakes

All Equine EDU assessment is formative — low stakes or no stakes. Low-stakes quizzing preserves the testing effect without test anxiety and is how the effect was demonstrated in classroom research [Roediger, Agarwal et al.]. Do not introduce gated, single-attempt, or timed exams without a specific reason.

### 4.3 Formats for visual-identification subjects (colors, markings, anatomy, tack)

Evidence-ranked guidance:

1. **Interleaved image-based questions** — present photos in mixed category order; never quiz ten leg markings in a row [Kornell & Bjork; Firth].
2. **Novel-exemplar testing** — quiz images should not be the same photos used in the Viewing Room; transfer to new examples is the actual goal of category learning [Kornell & Bjork; Kang].
3. **Near-miss distractors** — wrong answers come from visually similar categories to force discrimination [Kornell & Bjork].
4. **Labeling/hotspot items** — for anatomy and tack parts, clicking or dragging labels onto the image keeps words and picture together (contiguity) [Mayer].
5. **Repeat across courses** — visual categories reappear in later quizzes (spacing) [Dunlosky].

### 4.4 Guidance fading by tier

Foundations: worked example → guided practice with hints → independent items. Expanding Knowledge: minimal worked examples, mostly independent problem-solving and judgment tasks [Sweller; Kalyuga].

## 5. Difficulty Scaling Guide (Round Pen → Schooling Ring → Loft tier)

*Canon C2: tier names below are canonical (Round Pen / Schooling Ring / Loft tier); the aliases Foundations / Core Studies / Expanding Knowledge are retained once here for reference. No thresholds change.*

The three tiers map onto established equine-program progressions: 4-H advancement levels (mastery of each level before the next; safety and identification first) [4-H], USPC D→C→B/A (concrete care tasks → independent management → reasoning and evaluation) [USPC], and CHA Levels 1–4 (written + practical test gates each level) [CHA].

| Dimension | Round Pen *(Foundations)* | Schooling Ring *(Core Studies)* | Loft tier *(Expanding Knowledge)* |
|---|---|---|---|
| **New concepts per course** | 3–4 | 4–6 | 5–7, plus integration of prior concepts |
| **Bloom ceiling** | Remember/Understand | Apply/Analyze | Analyze/Evaluate |
| **Worked examples** | Every major concept | Major concepts only, partially faded | Rare; replaced by problems [Kalyuga] |
| **Terminology** | Everyday words first, term introduced after the idea | Terms used directly, defined on first use | Industry vocabulary assumed from lower tiers; only new advanced terms defined |
| **Content framing** | What it is, how to recognize it | How it works, when to use it | Why, trade-offs, evaluation, industry context |
| **Practice items** | Recognition (match, sort, label) | Application (classify new cases, explain) | Judgment (rank, justify, oral-reasons-style prompts) |
| **Quiz composition** | 100% current course by default | ≥ 20% prior-course items | ≥ 30% prior items; scenario-based questions |
| **Reading level** | Grade 5–6 | Grade 6–8 | Grade 8–9 max |

Concept-count rationale: working memory holds roughly 3–5 chunks for material that isn't yet connected to prior knowledge [Cowan; Sweller]. The specific 3–4/4–6/5–7 bands are this template's application of that limit, not numbers from a study — treat them as strong defaults, not law. Beginners can handle more *information* only when it is chunked into fewer *concepts*.

What stays constant across tiers: page flow (Section 1), voice (Section 6), feedback rules, and accessibility standards. A learner moving from Foundations to Expanding Knowledge should feel the content deepen, not the interface change.

## 6. Voice and Formatting Rules

Folded in from the Equine EDU standardization rules and project content guardrails:

- **Lesson prose is third-person instructional.** No "you" in lesson body text. Write "A horse's height is measured in hands," not "You measure your horse in hands."
- **Imperative voice is allowed only in activity and navigation instructions** ("Drag each label to the correct marking." "Select the best answer.").
- Tone: educational, welcoming, professional, beginner-friendly, encouraging, clear, family-friendly. Never corporate, sales-y, overly academic, overly casual, or emoji-decorated.
- Explain before naming: at Foundations, describe the idea in plain words, then attach the term.
- Age-neutral wording — the same lesson serves a 10-year-old 4-H member and an adult owner. Avoid both talking down and textbook density.
- No citations, footnotes, source lists, or "according to" statements in learner-facing content. Sources live in internal files like this one.
- **No difficulty labels or program names in learner-facing content.** Rendered course text never calls itself or the learner *beginner, intermediate, novice,* or *advanced,* and never names youth/industry programs (4-H, FFA, Pony Club / USPC, CHA) as its audience or framing. The tier (Round Pen / Schooling Ring / Loft) already carries level, and those programs — like sources — are **internal** layout and research references only. This template and the other internal guides may cite 4-H / FFA / USPC / CHA and beginner/intermediate reasoning freely (they are large, useful sources for how to structure courses); the rendered course may not surface that verbiage to learners.
- Accuracy gates: health and veterinary content must align with AAEP guidance; breed facts with the relevant registry; care and management with university extension publications [AAEP; Extension]. If a fact can't be verified against such a source, it doesn't ship — state "additional verification is needed" in the draft instead.

Readability and accessibility (youth-facing standard):

- Target the reading-level ceiling in the Section 5 table; WCAG asks that content not exceed lower-secondary reading level (≈ grade 8–9) without a simpler alternative [WCAG 3.1.5]. Check with Flesch-Kincaid as an indicator, then human-review.
- Sentences average ≤ 20 words; define every term on first use; no unexplained jargon.
- Every image: descriptive alt text naming the distinguishing feature. Every interactive: operable by keyboard, with a text alternative for the information it conveys [CAST; WCAG].
- Offer multiple means where the platform allows: text + image for every key concept; learners show knowledge through more than one activity format per course [CAST].
