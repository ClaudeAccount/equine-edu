Two Activities to Build Your Skills

Use these activities to move from recognizing terms to genuinely understanding them. The matching game tests whether you can place each external structure in the right region. The assessment quiz tests whether you understand what each part reveals about a horse's soundness, conformation, and condition.

Activity 1

Region Match

Match each external structure on the left to the body region it belongs to on the right. Select a term, then select its matching region. A new set loads each round.
