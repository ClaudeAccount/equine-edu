# T10 — Label It (Pin / Hotspot Game)

**Covers existing games:** pin-the-marking, label-horse, label-western-saddle, label-western-bridle, label-driving-harness, label-driving-bridle, anatomy-challenge (labeling rounds)
**Skill level:** Application (Bloom: Apply) — second rung, alternative to T09 for parts-and-places subjects
**Institutional model:** The classic 4-H/USPC "parts of the horse" diagram test — labeling a diagram is the standard assessment for anatomy and tack across every institution reviewed. Mayer's contiguity principle: words placed on the image beat words near the image.

Learner drags labels onto target zones on a photo or diagram (or clicks the named zone).

## Required structure

1. **Instruction line** (imperative, ≤ 25 words): "Drag each label to the correct part of the saddle."
2. **Base image** — one large, clear, side-on photo or diagram; target zones generous enough for touch on tablet.
3. **Label bank** — 6–12 labels per round. For courses with more parts, run multiple rounds grouped by region (front of horse / hindquarters) rather than one 25-label monster.
4. **Feedback per placement** — correct: label locks in. Incorrect: label returns; second miss highlights the correct zone briefly and shows the part's one-line description.
5. **Round summary** — parts correct, most-missed parts listed, replay + onward links.

## Content rules

- Label wording matches the catalog page exactly.
- Two difficulty settings where feasible: word bank visible (Round Pen) vs. type-or-recall variants (Learning Loft) — guidance fades as expertise grows (Kalyuga).
- Keyboard alternative: select label → select zone from a list.

## Do not

- Use a different image style per course — pick one diagram treatment site-wide and stick to it.
- Crowd more than 12 active targets on one image.

## QA checklist

- [ ] 6–12 labels per round, regions split if more
- [ ] Second-miss reveals zone + description
- [ ] Tablet-sized touch targets
- [ ] Keyboard path works
