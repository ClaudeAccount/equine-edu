# T08 — Match & Memory Game

**Covers existing games:** face-marking-match, leg-marking-match, term-match, discipline-match, job-match, marking-memory, leg-marking-memory, anatomy-memory, vitals-memory, color-compare
**Skill level:** Recognition (Bloom: Remember) — the first rung of the Training Barn ladder
**Institutional model:** Horse bowl flashcard drilling and 4-H identification card games; mechanism is retrieval practice — each flip/match attempt is a recall event (Roediger & Karpicke).

One template, two modes:
- **Match mode:** pair image ↔ name (or term ↔ definition) from two visible columns or a grid.
- **Memory mode:** the same pairs, face-down. Memory mode adds engagement, not extra learning — use it as the variant, not the default.

## Required structure

1. **Instruction line** (imperative, ≤ 25 words): "Match each photo to its marking name. Select a card to begin."
2. **Item set** — 6–10 pairs per round. Pull from the course catalog only.
3. **Interleaved pool** — pairs from different item families mixed in one round (don't run an all-snip round).
4. **Feedback per match** — correct: name + the one-line identifier from T04 ("Star — white patch between the eyes"). Incorrect: "Not a match," and on the second miss, show the identifier as a hint.
5. **Round summary** — pairs correct, invitation to replay with a reshuffled set, link onward.

## Content rules

- Images: catalog or Viewing Room photos are fine here (this is practice, not the quiz).
- Term↔definition variants use the exact one-line identifiers from the catalog page — same wording everywhere.
- Randomize order each round.

## Do not

- Score, time-pressure, or limit attempts (a casual round timer for replay fun is fine; failure states are not).
- Include any item not on this course's catalog page (except designated review items from the prior course).

## QA checklist

- [ ] 6–10 pairs, randomized, interleaved
- [ ] Feedback repeats the catalog identifier verbatim
- [ ] Replay reshuffles
- [ ] All items from this course (+ flagged review items only)
