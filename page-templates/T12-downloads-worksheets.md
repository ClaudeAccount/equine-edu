# T12 — Downloads & Worksheets Page

**Covers existing pages:** all `activities/downloads/index.html` and `*-worksheets/index.html` pages
**Skill level:** Practice extension — offline reinforcement
**Institutional model:** 4-H project books and record sheets — every 4-H and Pony Club program pairs digital/classroom learning with printable worksheets, because offline practice serves barn aisles, classrooms, and club meetings. This is also Equine EDU's instructor/parent-facing surface.

## Required structure

1. **Intro line** (1–2 sentences) — who these are for (self-study, club meetings, classrooms) and that they're free to print.
2. **Download cards** — one card per printable. Each card: title, type tag (Worksheet / Answer Key / Flashcards / Study Sheet), one-line description of the activity (≤ 15 words), page count, download button (PDF).
3. **Suggested use note** (optional, ≤ 50 words per item) — a one-liner for instructors: "Works well as a barn scavenger-hunt checklist."
4. **Back to Training Barn link.**

## Standard printable set per course

- **Identification worksheet** — label/match items from the catalog (mirrors T08/T10 digitally).
- **Answer key** — separate file, clearly labeled.
- **Study sheet** — one page: every catalog item + its one-line identifier. This is the horse-bowl prep artifact; keep wording identical to the catalog page.
- Optional: flashcard sheet (cut-out pairs), vocabulary puzzle (crossword uses retrieval and is acceptable; word searches are engagement-only — label them "Just for Fun" and never count them as practice).

## Content rules

- Every worksheet maps to module objectives, same as digital activities.
- PDFs follow the same voice rules: third-person instructional prose, imperative activity instructions.
- File naming: `<course-slug>-<type>.pdf` (e.g., `face-markings-study-sheet.pdf`).

## Do not

- Put content on worksheets that the course pages don't teach.
- Ship a worksheet without its answer key.

## QA checklist

- [ ] Study sheet wording matches catalog identifiers verbatim
- [ ] Answer keys present and separate
- [ ] "Just for Fun" labeling on engagement-only puzzles
- [ ] Consistent PDF file naming
