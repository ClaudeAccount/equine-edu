# T24 — Quick Reference Card

**Status:** Adopted (modified) — topic-specific performance-support asset, printable + digital
**Placement:** Produced per *topic* (not per course); distributed through the T12 pages of every course that teaches the topic, listed in the T14 Reference Library, and collected in a Learning Loft card set. The digital version is also an organic-traffic asset (saveable, pinnable, image-searchable), parallel to T23's acquisition role.
**Required or optional:** Recommended generally; **required for safety-critical topics** (vital signs, emergency readiness, hazard checks) where at-need access matters most.
**Institutional model & evidence:** Extension programs publish exactly this artifact (laminated vital-signs charts, pocket guides); AAEP publishes normal-parameter references. The learning-science framing is honest and specific: reference cards are **job aids / performance support** — their documented value is accurate, consistent task performance at the point of need and reduced cognitive load during the task (Rossett & Schafer), *not* long-term retention. Retention is the job of retrieval tools (T15/T16/T19). A barn aisle at 9 pm with a colicky horse is a performance moment, not a learning moment — that is the moment this template serves.

## Answers to the proposal's research questions

- **Improves retention?** Not directly — offloads memory rather than building it. Adopted for performance support, with the card linking back to the course for actual learning.
- **Actively used?** Strong practitioner evidence and unanimous industry convention (extension quick sheets, pocket guides); flagged as convention + cognitive-load rationale rather than experimental learning gains.
- **Distinct from worksheet/study guide/library?** Yes — see comparative analysis in TEMPLATE-SYSTEM-V2.md §7.
- **Course-specific or topic-specific?** Topic-specific: one canonical Vital Signs card serves the vital-signs course, future health courses, instructor guides, and standalone downloads. Course-specific cards would fork the truth.
- **Printable-only or digital?** Both from one source: print-first design, digital page rendering the same content.

## Required structure (one card = one topic, one printable side)

1. **Title bar** — topic name + Equine EDU mark (the share/print asset carries attribution).
2. **The reference body** — one of three fixed layouts:
   - *Values layout* (vital signs): table of parameter → normal adult range → how measured (≤ 10 words) → ⚠ "call the vet" threshold.
   - *Identification layout* (colors, markings, tack): grid of image thumbnail + name + one-line identifier (verbatim from T04).
   - *Diagram layout* (parts of horse, saddle): one labeled diagram, numbered labels with a compact legend.
3. **Critical-action strip** (safety topics only) — 2–4 line emergency guidance ("Heart rate over 60 at rest + pawing/rolling → call the veterinarian now").
4. **Footer** — "Learn this topic: [course name + short URL]" + version date (cards carry verified values; the date signals currency).

## Content rules

- **One side, no prose.** Tables, labels, thresholds only; if a sentence needs writing, the content belongs in a course. Word ceiling ≈ 120.
- Every value verified against AAEP/extension sources; identification wording verbatim from the catalog; diagram labels verbatim from T10 labels. A card never states anything the platform doesn't teach.
- Normal ranges given for the adult horse at rest, with a one-line note where foals differ materially — never invented precision.
- Print spec: letter/A4, high-contrast, legible at arm's length, survives black-and-white printing and lamination.
- Digital version: same content, descriptive alt text per element, downloadable as PDF and as a shareable image.

## Do not

- Add practice questions, blanks, or activities (that's a worksheet, T12).
- Add explanations or "why" content (that's the course).
- Create per-course variants of the same topic card.
- Ship a safety card whose thresholds haven't been verified against AAEP/extension guidance in the same change.

## QA checklist

- [ ] One topic, one side, ≤ ~120 words, no prose
- [ ] Values/wording verbatim from verified sources and catalog
- [ ] Vet-threshold strip on health/safety cards
- [ ] Course link + version date in footer
- [ ] Same source renders print PDF + digital page
