# T03 — Concept Foundation Page

**File slot:** `3-<foundation-topic>.html` (e.g., `3-face-anatomy`, `3-pigment-basics`, `3-saddle-bridle-parts`)
**Existing components:** `lesson-hero`, `lesson-wrap`, `concept-grid`, `visual-card`
**Institutional model:** USPC manuals and CHA level manuals always teach the underlying structure before the catalog (parts of the leg before leg markings; parts of the saddle before saddle types). Cognitive load theory: prerequisite schema first reduces the load of the main lesson (Sweller). Several current courses already do this — `face-anatomy` before `face-markings`, `pigment-basics` before `base-coat-colors`. This template makes that pattern official.

**When to use:** only when the main catalog page (T04) depends on structures or ideas the learner can't be assumed to have. Courses without a true prerequisite (e.g., vital signs) skip T03 and go straight to T04 — a 5-page course is correct in that case.

## Required sections (in order)

1. **Module objectives** — verbatim from T01, listed at top.
2. **Orienting visual** — one labeled diagram or photo of the structure being introduced, labels on the image (contiguity).
3. **Concept chunks** — 3–4 chunks max. Each: heading → 100–200 words → one visual or example. One concept per chunk.
4. **Worked example** (Round Pen and Schooling Ring tiers) — one fully stepped-through example: "To find the chestnut, start at the knee and move down…" Learning Loft tier replaces this with a practice problem.
5. **Check Your Understanding** — 1–2 ungraded retrieval questions, answer revealed on interaction.
6. **Key Terms recap** — term + one-line definition, bulleted.
7. **Continue CTA** to the catalog page.

## Content rules

- 400–800 words. This page is shorter than T04 — it sets up, it doesn't catalog.
- Explain before naming at Round Pen tier: describe the idea, then attach the term.
- Every term taught here must actually be used on the T04 page; otherwise cut it.

## Do not

- Preview the catalog items (don't show markings on the anatomy page).
- Exceed 4 concept chunks — split the course instead.

## QA checklist

- [ ] Objectives at top
- [ ] ≤ 4 chunks, one concept each
- [ ] Worked example present (or problem, Learning Loft)
- [ ] Retrieval check present
- [ ] Every term reused on T04
