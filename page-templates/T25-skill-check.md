# T25 — Skill Check ("Take It to the Barn")

**Status:** Adopted (modified) — criteria-referenced self-assessment checklist for hands-on skills; formative only
**Placement:** Optional final course element, linked from the T07 wrap-up, for **hands-on topics only** (vital signs, tack fitting and placement, handling, barn safety, stable management). Printable version ships in T12 with an observer sign-off line.
**Required or optional:** Situational — required for courses whose outcomes include a physical procedure; never used for screen-assessable content.
**Institutional model & evidence:** Practical demonstration is *the* mastery gate in every equine program reviewed — USPC certifications, CHA level tests (written + riding/practical), 4-H horsemanship levels, and CTE competency checklists. An online platform cannot verify physical performance, so the adopted form is the strongest thing it *can* honestly provide: a criteria-referenced checklist. The evidence makes criteria non-negotiable: unguided self-assessment is unreliable and weakest learners overrate themselves the most, while rubric/checklist-referenced self-assessment improves both accuracy and actual task performance (Metacognition & Learning, 2022; self-assessment accuracy literature). Concrete observable criteria are what separate a useful Skill Check from feel-good self-grading.

## Scope rulings from the proposal's examples

- **Vital signs, tack placement, barn safety** → T25. Physical procedures and real-environment evaluation.
- **"Horse Identification" (markings, colors, anatomy)** → **excluded; already T19.** Screen-assessable recognition is the Identification Challenge's job — duplicating it here was the proposal's one overlap.
- **"Recognize abnormal readings," "recognize unsafe equipment use"** → cognitive judgment → T11 Scenario Challenge (photo-based unsafe-gear spotting may also run as a T19 variant). T25 keeps only what must happen with a real horse, halter, or stall.

## Required structure

1. **Header + honest framing** (≤ 50 words) — this is a barn checklist, not a test or certificate; it is for the learner (and a helper) to see what's solid and what needs practice.
2. **Safety preamble** (required, fixed wording per skill category) — supervision expectations (youth work with an adult; everyone works with appropriate experienced supervision for unfamiliar skills), horse-handling preconditions, and a "learn in person first" flag on any skill unsafe to attempt from written instruction alone.
3. **What you need** — equipment/setting list ("a calm horse, halter and lead, stethoscope, a helper").
4. **Criteria checklist** — 5–12 items per skill. Each item is a single **observable behavior**, not a feeling:
   - ✗ "Understands pulse taking" → ✓ "Locates the digital pulse and counts for 15 seconds without losing it."
   - Scale per item: **Not yet / With help / On my own.** (Three levels — enough to show progress, too few to invite grade-like obsession.)
5. **Reference strip** — links the relevant T24 card and the course page for each criterion cluster.
6. **Reflection prompt** (1–2 questions) — "Which step took longest? What would make it smoother next time?" (the calibration moment).
7. **Practice-again guidance** — "Items marked *Not yet* or *With help*: revisit [page], then repeat in a few days." (spacing applied to motor practice).
8. **Printable variant (T12)** — same checklist + date line + observer signature line ("practiced with / observed by") for 4-H leaders, parents, instructors.

## Content rules

- Criteria are written from verified procedure sources (extension/AAEP/CHA-consistent technique); no invented technique details — anything unverifiable is omitted.
- Every criterion observable by a layperson helper; no criterion requires instructor judgment (those wait for T20).
- Results are private formative data: no scores, no badges, no stored "competency" — the platform never claims a learner can physically do anything.
- Third-person lesson voice does not fit a checklist; criteria use neutral behavior statements, instructions use imperative. "You" remains excluded from prose sections.

## Future hooks (design now, build later)

- **Instructor Area (T20):** the observer line becomes instructor verification; guides reference the same criteria.
- **Achievements:** criteria carry concept-taxonomy tags (T22 Phase 1), so a future badge system can hang off verified checks without rewriting content. Self-report alone never triggers an achievement.
- **Virtual Horse (T22):** skill tags map to gameplay actions (the health-check action exercises the vital-signs criteria in simulation — practice, not verification).

## Do not

- Call it a test, grade it, or certify from it.
- Include screen-assessable recognition skills (T19/T11 territory).
- Write vague self-rating items without observable behavior.
- Skip the safety preamble, ever.
