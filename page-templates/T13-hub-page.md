# T13 — Hub Page (Arena, Subject, Lesson Board, Quiz Corral)

**Covers existing pages:** `courses/index.html`, `round-pen/index.html` (arena hubs), subject category indexes, `lesson-board/index.html`, `quiz-corral/index.html`
**Institutional model:** Extension program landing pages and the USPC certification map — learners always see *where a course sits in the progression* before entering it. The hub's job is wayfinding, not teaching (QM Standard 1 at site scale).

One template, three levels of the same pattern:

| Variant | Lists | Example |
|---|---|---|
| **Arena hub** | Subjects within a tier | Round Pen → Colors & Markings, Anatomy, Riding Styles… |
| **Subject hub** | Courses within a subject, in order | Colors & Markings → Common Colors → Face Markings → Leg Markings |
| **Collection hub** | Cross-course items | Lesson Board (all courses), Quiz Corral (T23 fun quizzes), Learning Loft tools (T17 bank home) |

## Required structure

1. **Hero** — space name, one-sentence identity in the barn metaphor ("The Round Pen is where every horse — and every learner — starts."), tier indicator.
2. **Progression note** (1–2 sentences) — where this space sits: what comes before, what comes after (Round Pen → Schooling Ring → Learning Loft).
3. **Card grid** — one card per child item. Each card: title, one-line description (≤ 15 words), item count or time estimate, difficulty/tier tag, status if applicable (New). Same card anatomy on every hub.
4. **Recommended order cue** — numbered cards or a "Start here" badge on the first item. Subject hubs list courses in instructional order, not alphabetical (scaffolding is the point).
5. **One cross-link** — e.g., arena hub links to Quiz Corral challenges for that tier.

## Content rules

- Word budget: 100–250 total. Hubs navigate; they never teach.
- Barn-metaphor naming appears in the hero only — card copy stays plain and descriptive so beginners aren't decoding the metaphor to find content.
- Card metadata must be real (actual course counts/times), updated when courses ship.

## Do not

- Add instructional content, fun facts, or glossary terms.
- Order cards by recency or alphabet when an instructional order exists.
- Vary card anatomy between hubs — identical structure is what keeps the site from going helter-skelter.

## QA checklist

- [ ] Progression note present
- [ ] Cards in instructional order with "Start here" cue
- [ ] Card anatomy identical to other hubs
- [ ] ≤ 250 words
